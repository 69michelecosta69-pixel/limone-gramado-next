# LIMONE GRAMADO no iPhone

Para Maria e Bia usarem o sistema no iPhone:

1. Abrir no Safari:

```text
https://www.limonegramado.com.br/sistema
```

2. Tocar no botao de compartilhar.

3. Escolher:

```text
Adicionar a Tela de Inicio
```

4. Confirmar o nome:

```text
LIMONE
```

5. Entrar com:

```text
PIN: 0427
```

Os dados sao compartilhados entre Michele, Maria e Bia. Quando uma pessoa salva uma producao, compra, estoque, venda, contato, tarefa ou os numeros do Inicio, as outras pessoas veem a atualizacao online.

Observacao: usar sempre Safari para instalar no iPhone. Depois de instalado, abrir pelo icone LIMONE na tela inicial.
